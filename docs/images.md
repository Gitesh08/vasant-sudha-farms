# images.md — placeholder slots & shot list

All slots render through `<Photo slot="ID" />`. Until `src` is set, a designed placeholder shows. Aspect ratios are *display* ratios; supply originals
at ≥ 2× the largest display size, landscape unless stated, sRGB JPG (WebP/AVIF generated by Next).

**Upload protocol:** save as `public/images/<slot-id-lowercase>.jpg` (e.g. `hero-01.jpg`) → set `src: "/images/hero-01.jpg"` in `src/content/images.ts`
(or assign in Admin → Media once built) → keep alt text unless it no longer matches the photo. Max 2400px long edge, ~300–500 KB after export.

## Shot-list tips for whoever photographs
Shoot at golden hour and mid-morning; keep horizons level; include human-scale details (chairs, towels, fruit); avoid HDR glow and heavy filters; capture vertical versions of
hero and stay shots for arch crops; get permission for any faces; note which rooms are real so slots can be labelled correctly.

## Placeholder behaviour (spec for `<Photo>`)
Flat tint + faint wave lines + caption `SLOT-ID · short description`. Same aspect/shape as final. No broken-image icons. Caption hidden when
`NEXT_PUBLIC_SHOW_PLACEHOLDER_CAPTIONS=false`.
